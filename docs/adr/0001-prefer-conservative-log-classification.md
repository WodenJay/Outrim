# 日志来源识别优先避免误判

日志来源误判会把数据查询、函数索引等非日志输出送入日志截尾规则，丢失模型可见信息；漏识别则会错过压缩机会。因此，日志来源识别采用固定、明确的命令名单：对用途清楚、压缩收益与信息保留效果有充分依据的命令形式，应主动纳入支持，不能以保守为由放弃已知有效的优化。只有在来源判断或压缩效果不确定时，才优先避免误判，暂不扩大匹配；解释器名称本身不足以证明输出是日志。

不确定的形式交给 record 机制作为后续改进的兜底：在启用记录并积累样本后，人工分析压缩诊断数据，验证效果并逐项补齐有依据的名单形式。record 不是推迟已知有效优化的理由，也不会自动识别遗漏或在运行时补做日志压缩；未进入日志规则的输出仍可按其他现有适用规则处理。

除非后续发现并验证了足够可靠的通用识别方法，或项目所有者主动推翻本决策，否则持续遵循“有依据则优化，不确定则保守并通过 record 验证”的取舍，不为提高覆盖率重新引入缺乏依据的宽泛推断。
