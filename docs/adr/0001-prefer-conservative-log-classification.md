# 日志来源识别优先避免误判

日志来源误判会把数据查询、函数索引等非日志输出送入日志截尾规则，丢失模型可见信息；漏识别则只是错过该规则的压缩机会。因此，日志来源识别优先避免误判：采用固定、明确的命令名单，宁可暂时漏掉真实日志命令，也不通过解释器名称或宽泛启发式扩大匹配。

漏识别交给 record 机制作为后续改进的兜底：在启用记录并积累样本后，人工分析压缩诊断数据，逐项补齐有依据的名单形式。record 不会自动识别遗漏或在运行时补做日志压缩；未进入日志规则的输出仍可按其他现有适用规则处理。

除非后续发现并验证了足够可靠的通用识别方法，或项目所有者主动推翻本决策，否则持续遵循这一取舍，不为提高覆盖率重新引入宽泛推断。
